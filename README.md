# SimpleBashUtils

## Состав проекта
Проект состоит из одноименных с реализуемой утилитой папки *cat/* и *grep/*
Папка *common/* объединяет общие функции между утилитами


## Запуск программы
Шаг 1. Перейти в нужную папку
> cd ~/cat
Шаг 2. Выполнить сборку проекта командой make
> make

В результате сборки появится исполняемый файл, который можно запускать как утилиту cat с входными параметрами, либо же можно запустить имеющийся скрипт для проверки работоспособности программы на некоторых тестах
> ./test_cat.sh


Аналогичные действия следует проводить и для запуска утилиты grep.
